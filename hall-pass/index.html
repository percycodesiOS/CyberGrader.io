Using this desk
  1. Open staff access and set a PIN on this iPad. Approve the card and choose how long the trip may run.
  2. Select Depart and scan the approved card when the trip begins.
  3. Select Arrive and scan when the student reaches the destination. Select Return when the trip is finished.
  4. A repeated scan in the same step makes no duplicate. An expired, unused approval cannot start a trip. A late arrival or return is still recorded so the student stays accounted for.
  5. Use Return to close an open trip even if an arrival was missed. Approve the card again for its next user.

Pair a keyboard-style Bluetooth/USB scanner with the iPad and configure it to end with Enter or Tab. Printed cards use Code 39 text CIRC-001 through CIRC-100. Until the hardware is checked, type the number and tap Record. All steps use this one device; another classroom device does not share these records. This tool does not replace official attendance.

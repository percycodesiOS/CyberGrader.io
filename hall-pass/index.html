How to use CIRC Check-In
  1. Approve. The teacher opens Staff access, enters the student’s name, a code from 1–100 and the expected visit time, then approves.
  2. Register. The student scans that code to register the approved visit. The list shows the expected time.
  3. Arrive. When the student reaches CIRC or ECTV, select Arrive and scan the same code.
  4. Finish / return. Select Finish / return and scan when the visit is over. The code can then receive a new approval.

All three scans use this same computer and browser. The code can be kept at the desk; the app does not require a carried paper pass. A repeat scan in the same step adds no duplicate. Finish can close a registered visit even if arrival was missed. Staff can cancel an unused approval.

Scanner trouble: click Ready to scan, then scan once. If nothing appears, open Notepad on the school computer and scan there. The original cards use Code 39; newer presigned and grayscale cards use Code 128. The handheld scanner must support and enable the type you printed. Configure Enter or Tab after each code. The app accepts CIRC001 and CIRC-001, with optional Code 39 stars or standard Code 39/128 identifiers. Typing 1–100 and clicking Record is always available.

Approvals end at New York midnight. A registered student stays visible until the visit is finished, even after expiry. There is no account, roster upload or cross-device sync. This tool supplements teacher supervision and does not replace official attendance.

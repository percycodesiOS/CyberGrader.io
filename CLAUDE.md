# PercyCodes Design System — project rules

## Writing / punctuation
- **Never use em dashes (—).** Use en dashes (–) with spaces, or an ellipsis (...) instead. This applies to all copy in app.html, index.html, and any feedback/email templates.

## Brand
- Favicon / brand mark is a white "P" on a raspberry (#E11D74 → #B01259) rounded-square tile (assets/favicon-*.png). The footer lockup pairs this tile with "PercyCodes" in Sora (white "Percy", raspberry "Codes"). Do NOT use the old glossy pink comic sticker (assets/percy-logo.png) anymore.
- Email sign-offs use the `[Your Name]` placeholder, auto-filled from the Teacher Name field in the user menu.

# MYnecraft publication host

MYnecraft development moved to https://github.com/percycodesiOS/MYnecraft on September 29, 2026. Make game/landing/asset changes in that source repository. Use its scripts/stage-release.mjs to prepare tested releases into a clean clone of this host, review the diff and verify the existing live URLs after an authorized normal push.

This repository retains its name and GitHub Pages main/root configuration to preserve existing student links and browser-save origin. Do not rename/delete it, redirect the game, or independently develop another game copy here. Preserve unrelated CyberGrader and GameBash files and all history. CIRC-HQ is a separate repository.

The existing public addresses remain:
- https://percycodesios.github.io/CyberGrader.io/
- https://percycodesios.github.io/CyberGrader.io/game/mynecraft.html

mynecraft-release.json records the source commit and exact runtime hashes for the current prepared release. A new source push alone does not publish this host.
